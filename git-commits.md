# Git Repository and Commit History

## Step 1: Create the Project

```bash
mkdir code1
cd code1
git init
```

Create an `index.html` file containing a basic HTML page.

## Step 2: Make Three Meaningful Commits

```bash
git add index.html
git commit -m "Add initial HTML page"
```

Add headings, paragraphs, and semantic HTML elements to the page. 

```bash
git add index.html
git commit -m "Add semantic page structure"
```

Add CSS styling and improve the page layout.

```bash
git add index.html
git commit -m "Style page with responsive CSS"
```

## Step 3: Verify Commit History

```bash
git log --oneline
```
