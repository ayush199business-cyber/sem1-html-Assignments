CSS Box Model

Every HTML element is represented by a rectangular box made up of content, padding, border, and margin.

MARGIN — space outside the border
BORDER
PADDING
CONTENT
Text or other element content

Margin creates separation from neighboring elements.

Box Model Components

  1. Content: The text, image, or other material displayed inside the element.
  2. Padding: The space between the content and the border.
  3. Border: The line surrounding the content and padding.
  4. Margin: The space outside the border, separating the element from other elements.

CSS Example

.card {
    width: 250px;
    padding: 20px;
    border: 5px solid blue;
    margin: 15px;
    box-sizing: content-box;
}

With content-box, the width including padding and borders is 250 + 40 + 10 = 300 pixels. Margins add outside that width. With border-box, the specified width includes padding and borders.
