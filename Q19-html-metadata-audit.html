HTML Metadata Audit

Reviewing and improving metadata in HTML documents.

1. Purpose of Metadata

Metadata provides information about an HTML document. Most metadata is placed inside the head element and is not displayed as ordinary page content.

Appropriate metadata helps browsers interpret documents, provides descriptive information to search engines, and supports responsive presentation.

2. Metadata Elements Reviewed

HTML Metadata Audit Checklist
Element Purpose Audit Result
charset Declares the document character encoding. Included as UTF-8.
viewport Supports appropriate viewport sizing on mobile devices. Included.
description Provides a concise description of the page. Included.
author Identifies the author of the document. Included.
title Defines the document title shown in the browser tab. Included.
robots Expresses search engine crawling and indexing preferences. Included.
lang Identifies the document language on the html element. Included as English.

3. Metadata Best Practices

  1. Use UTF-8 character encoding.
  2. Include a viewport declaration for responsive browsing.
  3. Give every page a unique and meaningful title.
  4. Write a concise description relevant to the page.
  5. Use the correct language attribute on the html element.
  6. Keep metadata inside the head element.
  7. Ensure links and images have meaningful content and accessible names.
  8. Avoid adding metadata that does not accurately describe the page.

5. Audit Conclusion

The document includes character encoding, viewport, author, description, language, title, and robots metadata. These elements improve document clarity and provide useful information to browsers and search engines.

Note: The robots metadata expresses a preference; it does not guarantee that a search engine will index the page. The compatibility declaration is mainly relevant to legacy browser support.
