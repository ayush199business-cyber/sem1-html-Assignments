About This Project

A practical frontend development project.

This landing page was created as part of HTML and CSS coursework. It demonstrates how semantic structure and modern CSS techniques work together to create a maintainable, responsive interface.

The design uses reusable CSS variables, responsive grids, flexible components, and media queries to keep the layout consistent across devices.
