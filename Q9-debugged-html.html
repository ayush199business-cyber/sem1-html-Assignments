HTML Debugging and Correction

This assignment demonstrates common HTML errors, their corrected versions, and the reasons for making each correction.

Part 1: Buggy HTML Code

The following example intentionally contains missing tags, incorrect structure, and accessibility problems. 

<!DOCTYPE html>
<html>
<head>
    <title>My Student Webpage
</head>
<body>

    <h1>Welcome to My Webpage
    <p>My name is Ayush Sharma.
    <p>I am a BCAI student at Invertis University.

    <h2>My Skills
    <ul>
        <li>HTML
        <li>Programming
        <li>Problem Solving
    </ul>

    <img src="profile.jpg">

    <a href="https://github.com/ayush199business-cy">
        Visit My GitHub Profile

    <table>
        <tr>
            <th>Subject
            <th>Status
        </tr>
        <tr>
            <td>HTML
            <td>Learning
        </tr>
    </table>

</body>
</html>

Part 2: Corrected HTML Code

The following version corrects the markup and improves accessibility and document structure. 

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My Student Webpage</title>
</head>
<body>

    <h1>Welcome to My Webpage</h1>

    <p>My name is Ayush Sharma.</p>

    <p>I am a BCAI student at Invertis University.</p>

    <h2>My Skills</h2>

    <ul>
        <li>HTML</li>
        <li>Programming</li>
        <li>Problem Solving</li>
    </ul>

    <img src="profile.jpg" alt="Student profile photograph">

    <p>
        <a href="https://github.com/ayush199business-cy">
            Visit My GitHub Profile
        </a>
    </p>

    <table>
        <caption>Learning Progress</caption>
        <thead>
            <tr>
                <th scope="col">Subject</th>
                <th scope="col">Status</th>
            </tr>
        </thead>
        <tbody>
            <tr>
                <td>HTML</td>
                <td>Learning</td>
            </tr>
        </tbody>
    </table>

</body>
</html>

Part 3: Corrections Made

  1. Added the language attribute: Added lang="en" to identify the document language.
  2. Added character encoding: Included UTF-8 metadata to support standard text characters.
  3. Added viewport metadata: Included the viewport setting for appropriate display on mobile devices.
  4. Closed the title element: Added the missing closing title tag in the head section.
  5. Closed heading elements: Added closing tags for h1 and h2.
  6. Closed paragraph elements: Corrected the incomplete paragraph markup.
  7. Closed list items: Added closing li tags to each list item.
  8. Added image alternative text: Included an alt attribute to describe the image to users who cannot see it.
  9. Closed the hyperlink: Added the missing closing anchor tag.
  10. Corrected the table: Closed table headers and data cells and organized the table using thead and tbody.
  11. Added table accessibility: Included a caption and scope attributes for column headers.

Part 4: Conclusion

Debugging HTML helps identify and correct markup errors. Properly structured HTML improves readability, accessibility, maintainability, and browser consistency.

Note: The file profile.jpg must exist in the same folder as the HTML document for the sample image to appear.
