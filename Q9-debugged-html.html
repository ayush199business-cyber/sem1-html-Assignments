Q9. Debug and Correct a Buggy HTML File

This page demonstrates common HTML errors and their corrections.

1. Buggy HTML Code


<html>
<head>
    <title>My Web Page
</head>
<body>
    <h1>Welcome to My Website
    <p>This is my first paragraph.
    <img src="photo.jpg">
    <a href="https://example.com">Visit Website
    <ul>
        <li>HTML
        <li>CSS
    </ol>
</body>
</html>

Errors found:

  • Missing closing tags for the title, heading, paragraph, and link.
  • Missing meaningful alt text for the image.
  • List items are not properly closed.
  • The unordered list is incorrectly closed with an ordered-list tag.
  • Missing document language and character encoding declarations.

2. Corrected HTML Code


<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My Web Page</title>
</head>
<body>
    <h1>Welcome to My Website</h1>
    <p>This is my first paragraph.</p>
    <img src="photo.jpg" alt="A sample photograph">
    <a href="https://example.com">Visit Website</a>
    <ul>
        <li>HTML</li>
        <li>CSS</li>
    </ul>
</body>
</html>

3. Result

The corrected code has properly structured HTML elements, valid list markup, and an image with alternative text.
