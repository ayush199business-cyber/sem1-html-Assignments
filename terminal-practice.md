# Terminal Navigation Practice

## Commands and Their Uses

| Command | Purpose |
|---|---|
| `pwd` | Displays the current directory. |
| `ls` | Lists files and folders. |
| `ls -la` | Lists all files, including hidden files. |
| `cd foldername` | Enters a folder. |
| `cd ..` | Moves to the parent directory. |
| `cd ~` | Moves to the home directory. |
| `mkdir html-css` | Creates a directory. |
| `touch index.html` | Creates an empty file on Linux/macOS. |
| `cat index.html` | Displays a file's contents. |
| `clear` | Clears the terminal screen. |

## Practice Exercise

```bash
pwd
ls
mkdir html-css
cd html-css
touch index.html
ls -la
cd ..
pwd
```

**Result:** Practiced directory navigation, folder creation, file creation, and directory listing.

**Note:** The `touch` command is suitable for Linux/macOS terminals. In Windows PowerShell, use `New-Item index.html -ItemType File` instead.
